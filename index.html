What is Herbaryo?

Herbaryo is an interactive 3D mobile educational game designed to teach phytomedicine concepts through exploration, preparation mechanics, and step-by-step progression. The game aims to teach pharmaceutical students herbal medicine using an interactive and engaging gameplay experiences
